Human-in-the-Loop Outreach Agent

Disputes stall when the site with the answer doesn't reply. Three times a day this agent reads every waiting ticket, works out who to chase, checks who already replied, drafts the messages, and waits for a human to approve.

  9. 7
    Send + write the audit log
    never-message list re-checked before every send

Guardrails the agent can't talk its way around

🛑
Never sends without approval
The send step takes an approval callback and does nothing without it.
🚫
Never-message list
Enforced when drafting and again immediately before every send, @mentions included.
🤔
Never guesses a contact
No tagged contact means 'please advise', never a best guess.
🧮
Never drops a ticket
Every ticket lands in exactly one bucket; the run fails if counts don't reconcile.
🔒
Never rewords a template
Only the link changes; text is checked against the template exactly.
🙋
Never decides unclear cases
Reopened or ambiguous rejections are flagged for a human.
